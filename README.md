# Catálogo Oficial Cuero Barra 2026

Catálogo web de artículos de cuero genuino de Cuero Barra (Lima, Perú). Sitio estático, sin dependencias.

- **Editar productos, precios, imágenes o distritos:** `data.js`
- **Diseño y funcionamiento:** `index.html`
- **Publicación:** GitHub Pages desde la rama `main`.

Para probar localmente, abre `index.html` en el navegador.
